## 🎯 Sobre el Juego

**Numero-Secreto** transforma el clásico juego de adivinar números en una misión galáctica. Cuenta con una interfaz temática inspirada en Star Wars, efectos de audio dinámicos y un diseño intuitivo que guía al usuario mediante pistas en cada intento hasta descifrar el número correcto.

---

## ✨ Características Principales

* 🌌 **Temática Galáctica:** Interfaz y diseño visual inspirados en el universo de Star Wars.
* 🔢 **Adivinanza Interactiva:** Mecánica de juego clásica adaptada para desafiar tu intuición lógica.
* 🔊 **Feedback Auditivo:** Efectos de sonido integrados para acompañar las pistas y aciertos.
* 🔄 **Reinicio Rápido:** Opción para iniciar una nueva partida de forma inmediata.
* 📱 **Diseño Adaptable:** Funciona de manera fluida en diferentes navegadores y tamaños de pantalla.

## 💻 Ejecución Local

Para probar y jugar localmente en tu equipo, solo necesitas un navegador web moderno:

---

### Pasos de Instalación

1. **Clonar el repositorio:**
   ```bash
   git clone [https://github.com/Mario-Si3ri/Numero-Secreto.git](https://github.com/Mario-Si3ri/Numero-Secreto.git)

2. **Acceder al directorio del proyecto:**
   ```bash
   cd Numero-Secreto
   ```
3. **Abrir el juego:**
   Abre el archivo **index.html** directamente en tu navegador o utiliza comandos rápidos según tu sistema operativo:
   * **macOS:** ``` open index.html ```
   * **Windows:** ``` start index.html ```
   * **Linux:** ``` xdg-open index.html ```
